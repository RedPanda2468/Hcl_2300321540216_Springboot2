# Spring Boot Learning Journal

This folder records a gradual, beginner-friendly journey through Spring Boot. Each lesson is intentionally small and focuses on one concept. Read the lessons in numerical order and try the examples in the main project before moving on.

## Roadmap

The lessons move from Java and Spring fundamentals to REST APIs, dependency injection, configuration, persistence, validation, error handling, testing, and basic production practices.

These notes are learning material, not a claim that every topic is already implemented in the application.
